PROAIM TRAINER V3
=================

Esta versão evolui a V2 para uma versão pronta para publicação.

Incluído:
- 10 modos de treino com descrição e objetivo de cada exercício
- Reflex Test: clique em qualquer lugar da arena após o sinal; mede reação em ms
- Detecção de clique antecipado no Reflex Test
- Modo Ranqueado com sessão padronizada de 60 segundos
- Rating, rank, melhor score e partidas do modo Ranqueado
- Leaderboard local preparado para futura sincronização online
- Estatísticas, XP, desafios e personalização preservados
- Nenhuma interação/injeção no VALORANT

PUBLICAÇÃO
----------
O site pode ser publicado gratuitamente em serviços de hospedagem estática, como GitHub Pages, Cloudflare Pages ou Vercel.

IMPORTANTE SOBRE O RANKING GLOBAL
---------------------------------
O Ranqueado desta V3 já funciona localmente. Para ranking global/Brasil real, contas de usuário e estatísticas na nuvem, é necessário conectar um backend (por exemplo, Supabase) e substituir o leaderboard local por gravações autenticadas no banco.
